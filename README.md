# Begin To Vibe

A beginner's tutorial for vibe coding with Claude Code.

## What you need

- A GitHub account
- A Claude subscription (Pro or Max)

## Start the lesson

Click the button to open a ready-to-go coding environment in your browser:

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/artificial-axolotl/begin-to-vibe)

When it finishes loading, open the terminal and type:

```bash
claude
```

To log in the first time:

1. Choose **Claude account with subscription**.
2. Click the sign-in link Claude shows you, and approve access in your browser.
3. Copy the code the web page gives you.
4. Paste it back into the terminal and press **Enter**.

You're ready to go.
